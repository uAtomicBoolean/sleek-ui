# Project

This is a UI kit made for Slint using only Slint to be compatible with Rust, C++, Javascript and Python.

# Project structure
- The library itself is in `ui/sleek-ui`.
- The whole `ui/` folder contains both the library and the documentation.
- The `pages/` folder contains the documentation's content itself.
- The `components/` folder contains components used by the documentation.
- The documentation's and project's main entry file is `ui/app-window.slint`.

# Code Style
- Use 4-space indentation.
